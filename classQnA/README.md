# 수업 질문 대기열 PRD

## 개요

컴퓨터 실습 중 질문을 말로 꺼내기 어려운 학생이 웹에서 질문을 신청하고 자신의 대기 순서를 확인하는 서비스다. 선생님은 접수된 질문을 순서대로 열어 답변한다. 학생에게는 본인의 질문과 답변만 보인다.

---

## 목표 및 대상

- 대상: 컴퓨터 실습 수업의 학생과 담당 선생님
- 학생 목표: 손을 들지 않고 질문을 등록하고, 내 차례와 답변을 확인한다.
- 선생님 목표: 대기 질문을 한곳에서 확인하고 순서대로 답변한다.
- 성공 기준: 학생이 질문을 등록하면 본인의 대기 순서가 보이고, 선생님 답변 후 학생 화면에 답변이 표시된다.

---

## 핵심 기능

- 계정 및 권한: 학생은 이름, 비밀번호로 가입, 로그인하고, 선생님 계정은 1개만 사용한다.
  - 온라인에서는 선생님 추가 가입을 막고, 로그인한 계정의 역할에 맞는 화면을 보여준다.
- 질문 신청과 대기: 제목, 상세 내용 필수, 학생당 미답변 질문 1건, 내 순서 확인, 취소, 타 학생 질문 비공개.
- 선생님 답변: 대기 질문을 열어 답변하면 자동 완료되고 학생의 내 질문에 답변이 표시된다.
- 관리자 조회: 선생님만 DB 화면에서 계정과 질문 기록을 확인할 수 있다.

---

## 화면 구성

- 시작 화면: 회원가입과 로그인. 학생, 선생님 권한은 계정에 저장된 역할로 구분한다.
- 학생 화면: 질문 제목, 상세 내용 입력, 내 질문과 대기 순서 확인, 답변 전 질문 취소.
- 선생님 화면: 대기 중인 질문 목록, 질문 상세 확인, 답변 입력, 전송.
- DB 조회 화면: 선생님만 계정과 질문 기록을 확인한다.

---

## 기술 스택

- 프런트엔드: HTML, CSS, 바닐라 JavaScript로 화면과 API 호출 구현
- 백엔드: Node.js 22 내장 HTTP, crypto로 로그인, 권한, 질문 처리
- 데이터베이스: SQLite(node:sqlite)에 계정, 세션, 질문 저장
- 배포: GitHub에 소스 저장, Railway에서 서버 실행, 영구 볼륨에 SQLite DB 보관

## 범위 (할 것 vs 안 할 것)

### 포함 범위
- 학생 회원가입, 로그인, 선생님 계정 한 개, 역할별 화면과 접근 권한
- 제목, 상세 내용이 있는 질문 신청, 본인 대기 순서 확인, 답변 전 취소
- 선생님의 질문 답변, 답변 후 자동 완료, 본인 답변 확인
- 선생님 전용 계정, 질문 기록 조회

### 제외 범위
- 실제 학생 개인정보를 다루는 운영 서비스
- 파일 첨부, 푸시 알림, 여러 수업, 학교 관리, 통계 화면

---

## 보안 및 검수 기준

### 데이터 보호
- 비밀번호는 무작위 salt와 scrypt 해시로 저장하고, 로그인 세션은 HttpOnly 쿠키로 관리한다.
- 학생은 다른 학생의 질문 제목, 내용, 이름을 조회할 수 없고, DB 조회 화면은 선생님만 사용할 수 있다.
- 공개 시연에는 가상 이름과 질문만 사용한다.

### 검수 기준
- 학생이 제목과 상세 내용을 입력해 질문을 등록하면 본인의 대기 순서가 표시된다.
- 다른 학생 계정에서는 그 질문의 제목, 내용, 작성자 이름이 보이지 않는다.
- 선생님이 답변을 전송하면 질문은 완료 상태가 되고 해당 학생에게 답변이 보인다.
- 학생 계정으로 선생님 전용 DB 조회 API에 접근하면 거부된다.

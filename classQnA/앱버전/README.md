# 수업 질문 대기열 Windows 앱

[Windows 앱 ZIP 다운로드](https://github.com/nnooww/nnooww.github.io/releases/tag/classqna-app-v0.1.0) — Release의 Assets에서 `수업-질문-대기열-Windows.zip`을 받으세요. 압축을 풀고 `ClassQnA-win32-x64/ClassQnA.exe`를 실행합니다. 실행 파일만 따로 빼면 동작하지 않습니다.

앱은 기존 Railway 서버에 접속합니다. 학생과 선생님이 여러 PC에서 같은 질문·답변 DB를 사용하며, 화면은 3초마다 새 내용을 확인합니다. 인터넷과 Railway 서버가 켜져 있어야 합니다. 앱 자체 업데이트는 자동으로 되지 않으므로 새 Windows 앱 버전은 새 ZIP을 받아야 합니다.

GitHub Pages에서는 이 서버형 앱이 실행되지 않습니다. 현재 공개 서버에는 시연용 계정 설정이 남아 있으므로, 실제 학급 데이터를 쓰기 전 선생님 비밀번호와 학생 가입 정책을 서버에서 정비해야 합니다.
